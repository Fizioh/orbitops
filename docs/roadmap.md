# Phase roadmap

Detailed execution plan for OrbitOps. Prefer excellent workflows over breadth.

## Phase 0 — Foundation (current)

Repository, monorepo layout, Docker, CI, lint, docs, design tokens stub.

## Phase 1 — Mocked premium UI

Dashboard, orbit view, satellite detail, mission planner, scheduler, conjunction view with mock data.

## Phase 2 — Orbit core

Satellite model, TLE versioning, propagation, ground track, pass prediction + scientific tests.

## Phase 3 — Ground operations

Stations, antennas, communication windows, conflicts, scheduling.

## Phase 4 — Mission tasking

Targets, requests, feasibility, scoring, schedule integration.

## Phase 5 — Power + storage

Battery model, eclipse approximation, payload/comms draw, storage constraints.

## Phase 6 — Telemetry

Simulation engine, SSE/WebSocket, alerts, historical charts.

## Phase 7 — Conjunction

Events, workflow states, maneuver simulation (SIMULATION ONLY).

## Phase 8 — AWS

Terraform, ECS/Fargate, RDS, Redis, CloudFront, monitoring.

## Phase 9 — Open-source polish

README screenshots, live demo, seed scenarios, benchmarks filled, recruiter path.
